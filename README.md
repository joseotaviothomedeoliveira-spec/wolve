# Gerador de Atividades em PDF (A4)

Aplicativo web simples para criar folhas de atividade em PDF no formato A4 para professoras em Portugal, com foco em alunos do 1º ao 8º ano.

## Requisitos

- Python 3.10+

## Instalação

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Executar

```bash
python app.py
```

Abra `http://localhost:5000` no navegador.

## Testes

```bash
pytest
```
